[CRO-MUXON] Keyboard Shortcuts

Every shortcut Cro-Muxon uses, kept in sync with the current release. Global shortcuts work anywhere in Chrome; the rest only apply while the dashboard (or the new-pane start page) has focus.

GLOBAL (anywhere in Chrome)

  • Alt+Shift+CFocus the dashboard if it's open but not focused, otherwise toggle it open/closed
  • Alt+Shift+VSplit the active pane vertically
  • Alt+Shift+HSplit the active pane horizontally
  • Alt+Shift+DClose the active pane

DASHBOARD — full view

  • j / kor↓ / ↑Move the cursor down/up through panes
  • h / lor← / →Collapse the current workspace / expand the nearest collapsed one
  • Shift+K / Shift+JorShift+↑ / Shift+↓Jump to the previous/next workspace
  • Alt+Shift+K / Alt+Shift+JorAlt+Shift+↑ / Alt+Shift+↓Reorder the workspace under the cursor, swapping it with its neighbor one slot up/down. A workspace named "default" stays pinned to the top slot; without one, the whole list is freely reorderable
  • 0–9Jump straight to that workspace's number
  • /Filter panes by title (or by workspace name)
  • EnterSwitch to the selected pane
  • nNew workspace root
  • rRename the selected workspace
  • aGive the pane under the cursor a short alias, replacing its tab title in the list
  • Shift+AAnnotate the pane under the cursor in a small floating popup — autosaves as you type; f/Space show it read-only under the pane when zoomed
  • Shift+DClose every pane in the selected workspace
  • Shift+M / Shift+OFold every workspace closed at once / open them all back up
  • y / pYank the URL of the pane under the cursor / put it into another pane, without switching to either one
  • dBlank the pane under the cursor back to the built-in empty-pane start page, whatever it currently has open
  • for clickZoom the pane under the cursor to fill most of the screen (padded so the panes behind still peek out, and never covering the dashboard), without changing the workspace's layout — clicking an already-active pane does the same. Esc zooms back out, or click the zoomed pane again
  • SpaceSame zoom as f, but always jumps real focus onto the pane afterward, regardless of "Keep focus on navigator" — the default way to jump into a pane
  • : / oOpen a URL, with history/bookmark autocomplete
  • e / Shift+EExport the current/entire workspace(s) to a file
  • iImport a layout, added alongside what's already open
  • tToggle thin mode
  • cor(gear icon)Settings: "Keep visible" (see thin mode below), "Keep focus on navigator" (p/d update a pane silently instead of raising it), zoom padding, and Theme (Current/Tempered Terminal/Slate). Modal while open — every other key stops responding (the rest of the dashboard dims) except v/f, which toggle Keep visible/Keep focus on navigator directly, z/t, which rotate zoom padding/theme through their own presets (applied immediately), and c/Esc/q, which close it
  • q / EscClose the dashboard

DASHBOARD — thin mode

A narrow, icon-width strip listing just workspace names — a lightweight quick-switcher you can leave open at the edge of the screen instead of opening and closing the full dashboard each time.

  • j / kor↓ / ↑Move between workspace names
  • Alt+Shift+K / Alt+Shift+JorAlt+Shift+↑ / Alt+Shift+↓Reorder the selected workspace, same as full mode
  • EnterSwitch to that workspace's last-focused pane
  • /Search — matches pane titles too, showing a snippet under the workspace name
  • Shift+DClose every pane in the selected workspace
  • y / pYank / put a workspace's URL, same as full mode
  • dBlank the workspace's pane, same as full mode
  • for clickZoom / Esc to un-zoom, same as full mode
  • SpaceZoom and jump focus into the workspace's pane, same as full mode
  • e / i / nExport / import / new workspace, same as full mode
  • tBack to the full dashboard
  • q / EscClose the dashboard

NEW-PANE START PAGE

Fresh panes are popup windows with no toolbar, so this page stands in for the address bar. Alt+Shift+C opens the dashboard from here, same as anywhere.

  • (type)Search history/bookmarks or type a URL — the search box is always focused
  • EnterGo to the highlighted result or typed URL, or refocus the search box if nothing else is focused
