[CRO-MUXON] Changelog

v1.1.0 2026-08-28 · Feature update
  • New: press a on the pane under the cursor to give it a short alias — a label that replaces its tab title in the dashboard list, handy when the real page title is long or unhelpful.
  • New: press Shift+A to annotate the pane under the cursor — a small floating note docked over its corner, saving as you type. Reopening it shows whatever you already wrote instead of starting blank.
  • New: f (and Space) now show that note as a read-only strip right under the pane when you zoom in for a closer look, so it's there for context, not just for editing. A pane with no note zooms exactly as before, full size.
  • New: a pane with a note shows a small † marker in the dashboard list, so reminders on a workspace you just imported are easy to spot at a glance.
  • New: closing the annotation popup now returns you to the dashboard, instead of leaving focus wherever it happened to land.
  • New: in thin mode, a workspace named starting with an emoji shows just that emoji instead of the full name — the strip is narrow enough that the rest would usually get cut off anyway.
  • New Theme setting (gear icon, or c): switch between "Tempered Terminal" (a softer, desaturated green), "Slate" (a neutral dark theme with a single accent color), or the original CRT green. Slate is now the default for new installs and anyone who hasn't already changed this — the classic green is one click away in Settings. Changes apply immediately.
  • New: hovering a pane in the dashboard list now shows a subtle highlight.
  • Changed: Space now shrinks the dashboard down to its narrow strip before popping up the pane under the cursor, instead of leaving the full-width list open behind it.
  • Changed: reopening the dashboard while it's in its narrow "thin" mode now snaps it back to full width automatically.
  • Changed: exporting a workspace no longer stamps a timestamp onto the filename — exporting the same workspace again now overwrites its file, behind a confirmation prompt that shows the filename first.
  • Changed: simplified the empty-pane start page — larger text, it now follows your chosen Theme instead of always being the original CRT green, and the keyboard shortcuts list is tucked behind a small toggle instead of always taking up space. Pressing Enter there now always returns you to the search box, and the small corner icon for opening the dashboard is gone — Alt+Shift+C still opens it from anywhere.
  • Changed: Slate's selected-pane highlight is now a solid, high-contrast fill instead of a faint tint that was easy to miss.
  • New: choosing an empty pane in the dashboard now always jumps focus onto it regardless of "Keep focus on navigator" — its only real content is its own search box, so landing there without focus wasn't useful. Every other pane still respects the setting.
  • Fixed: an update landing while the dashboard (or an annotation popup) was open could leave the old window behind as an empty, broken frame.
  • Fixed: the empty-pane start page's "Keyboard shortcuts" toggle didn't actually show or hide anything, and the list is now one shortcut per line instead of a two-column layout that wrapped some entries awkwardly.
  • Fixed: right-clicking the empty-pane start page showed no context menu at all. It's an ordinary pane like any other, so it now gets the same right-click menu (split, close, open navigator) as any other pane.
v1.1.1 2026-08-29 · Bug fix
  • Fixed: the empty-pane auto-focus behavior added in 1.1.0 was too broad. It now only applies to pressing Enter on an empty pane in the full-width dashboard — clicking a pane, and anything in thin mode, respect "Keep focus on navigator" like every other pane again.
  • Fixed: the read-only annotation strip (f/Space, shown under a zoomed pane) looked exactly like an editable text box but silently ignored anything typed into it. It's now genuinely editable and saves as you type, just like the Shift+A popup.
v1.0.3 2026-08-27 · Feature update
  • New: press Space on the pane under the cursor to zoom it, same as f, but always jump real focus onto it afterward regardless of "Keep focus on navigator" — the default, unambiguous way to jump into a pane.
  • New: right-click a link on any page — "Open link in New Cro-Muxon workspace" opens it straight into a fresh workspace, skipping the copy-then-paste round trip, and brings the navigator into view with the new pane already selected.
  • New: right-click any page for mouse equivalents of split vertically, split horizontally, close pane, and open navigator — each item shows its keyboard shortcut too. Right-click the dashboard itself for its own menu: new workspace, import/export the current workspace, fold/unfold every workspace at once, and close navigator.
  • New: Alt+Shift+Up/Alt+Shift+Down (or Alt+Shift+K/Alt+Shift+J) in the dashboard reorders the workspace under the cursor, swapping it with its neighbor one slot up/down. A workspace named "default" stays pinned to the top slot.
  • Fixed: closing the dashboard while a pane was zoomed left it stuck at its near-fullscreen zoomed size. Every way the dashboard can close now un-zooms it too.
v1.0.2 2026-08-26 · Feature update
  • New thin mode: press t to shrink the dashboard to a narrow strip of just workspace names — a lightweight quick-switcher you can leave open at the edge of the screen instead of opening and closing the full dashboard each time.
  • New "Keep visible" setting (gear icon, or c) shrinks the active workspace's rightmost pane(s) just enough that the dashboard is never covered by them in the first place. Settings is modal while open: v/f toggle "Keep visible"/"Keep focus on navigator" directly, z rotates zoom padding through a few presets (live if a pane is currently zoomed), and everything else dims and pauses until you close it.
  • Alt+Shift+C now focuses the dashboard first if it's open but not the focused window, instead of always closing it — a second press closes it once it's already focused.
  • New: press f — or click an already-active pane — to zoom it to fill most of the screen without touching your actual layout. Press Esc, or click it again, to snap it right back.
  • New: y/p yank a pane's URL and put it into another pane, without switching to either one.
  • New: d blanks the pane under the cursor back to the empty-pane start page, whatever it currently has open.
  • New "Keep focus on navigator" setting: when on, actions like p and d update a pane in the background instead of briefly switching to it first.
  • h/j/k/l now work as vim-style navigation throughout the dashboard, alongside the arrow keys.
  • / live-filters the pane list as you type, by pane title or workspace name.
  • Click a workspace's header to collapse it out of the way; Shift+M/Shift+O fold or unfold every workspace at once.
  • Shift+D closes every pane in the selected workspace at once. Shift+↑/Shift+↓ jumps to the previous/next workspace instead of stepping pane by pane, and a number key jumps straight to a given workspace.
  • Your layout now survives a full browser restart on its own, not just a crash.
  • Fresh, empty panes now open a small start page with a working search box and quick access to the dashboard, instead of Chrome's blank New Tab page.
  • Fixed several cases where the dashboard, or a pane you just created/activated/zoomed, could silently lose keyboard focus.
  • Fixed dragging a pane's border not always resizing every other pane that actually shares that edge.
  • Fixed a new pane sometimes not becoming the visible/active one right after it was created.
v1.0.1 2026-08-25 · Bug fix
  • Fixed workspace splitting sometimes leaving a pane stuck showing a wrong, scaled-down frame until you clicked or pressed a key.
  • Fixed the pane picker opening full-screen instead of as a narrow panel when the active window was already in native fullscreen.
  • Fixed the dashboard's shortcut legend showing key combos that didn't actually do anything — it now shows the real shortcuts.
  • Fixed the dashboard's version number sometimes showing an outdated value.
  • Redesigned the toolbar icon to be clearer at small sizes.
v1.0.0 2026-08-24 · Initial release
  • Tile any window into panes, horizontally or vertically, from the keyboard.
  • Drag one pane's edge and its neighbor resizes to match, just like a terminal multiplexer.
  • A retro dashboard to jump between panes, rename workspaces, and open URLs — with local history/bookmark autocomplete.
  • Save your entire tiled layout to a file and load it back later.
  • 100% local: no network requests, no data collection.
